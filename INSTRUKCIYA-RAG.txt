Документы и поиск (RAG)
=======================

По умолчанию PDF/Word кладите в папку:  my-docs  (рядом с этим файлом).

Другую папку на диске задаёт IT в файле .env:
  HOST_DOCS_DIR=...
  DOCS_DIR=/app/...

Полная инструкция:
  D:\Project_AI_Assistent\knowledge\user-guides\docs-to-ai-rag-kratko.md

Запуск и индексация:

  cd D:\Project_AI_Assistent\docs-to-ai\repo
  docker compose up -d
  docker exec docs-to-ai uv run python -m app.scan_all_my_documents
