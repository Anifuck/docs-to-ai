# Поиск по документам (RAG) — инструкция

Сервис индексирует PDF и Word и отдаёт их помощнику в Cursor.

---

## Куда класть файлы

Папка **docs-for-index** в корне этого репозитория (можно в подпапках).

Другую папку на диске подключает IT в `.env` (`HOST_DOCS_DIR`, `DOCS_DIR`).

---

## Запуск (Docker Desktop должен быть включён)

```powershell
cd D:\Project_AI_Assistent\docs-to-ai\repo
docker compose up -d
```

Контейнер **docs-to-ai** в Docker Desktop — статус Running.

---

## Индексация (после первого запуска и после новых файлов)

```powershell
docker exec docs-to-ai uv run python -m app.scan_all_my_documents
```

---

## Остановка

```powershell
docker compose down
```

---

## Cursor (настраивает IT)

MCP: http://127.0.0.1:38777/mcp
